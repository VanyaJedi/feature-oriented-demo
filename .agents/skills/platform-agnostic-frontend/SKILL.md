# Platform Agnostic Frontend

Следуй разделу платформенных API в [ADR](../../../docs/adr/0001-architecture.md).
Команды и пути к исходникам ниже отсчитываются от корня репозитория.

## Доступ к окружению

- Доступ к `window`, `document`, `navigator`, storage, observers, workers и другим
  браузерным API находится в `src/shared/platform`. В остальном коде используй
  публичные accessors через `@shared/platform`.
- Сейчас существует `getBrowserDocument()`. Не предполагай наличие других
  accessors: сначала проверь экспорт, при необходимости добавь функцию.
- В адаптере читай API через `globalThis`, проверяй наличие и подходящий тип.
  Защитная проверка должна охватывать само чтение, если getter может бросить ошибку.
- Не читай DOM/storage в module scope переиспользуемых модулей и не запускай
  браузерные побочные эффекты из конструкторов сервисов.
- `src/main.tsx` — браузерная точка запуска: она может получить root через
  accessor и сообщить об отсутствии обязательного DOM-элемента. Не распространяй
  это исключение на бизнес-модули.

## Поведение при отсутствии API

- Для необязательной возможности допустимы `null`, fallback или пропуск операции.
  Для обязательной — понятная ошибка, которую может обработать вызывающий код.
- Для storage обрабатывай отсутствие хранилища и ошибки отдельных операций
  чтения/записи; получение объекта не гарантирует успешность записи.
- Для DOM-фабрик допускай `HTMLElement | null`, если элемент необязателен.
- Если понадобятся animation frame, observers или подписки, добавляй accessors
  и согласованную очистку ресурсов. Не создавай их заранее ради универсальности.
- В демо нет SSR. Не добавляй серверный runtime ради проверки импортов. Если SSR
  появится, пользовательское состояние и контейнер потребуется изолировать на запрос.

## Проверки

При изменении кода проверь обращения к браузерным API через `rg` и `npm run lint`;
при изменении типов также выполни `npm run typecheck`. ESLint ловит прямые имена
и известные свойства globalThis, но не все способы обхода: проверь новые
адаптеры и отсутствие побочных эффектов вручную. Не отключай правила в фичах
вместо добавления accessor. Если проверка недоступна, укажи команду и причину.
